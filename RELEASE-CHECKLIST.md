# DriverOS ONE — Release gate

## Comprobación técnica
- [ ] HTML válido; navegación sin enlaces internos rotos.
- [ ] Tests automatizados en verde.
- [ ] Sin secretos, tokens o claves en el repositorio.
- [ ] PWA instalable donde el navegador lo permita.
- [ ] Navegación y búsqueda accesibles mediante teclado.
- [ ] Diseño legible en pantalla ancha Tesla y teléfono.
- [ ] Calculadoras validadas con entradas vacías, cero y valores extremos.
- [ ] Enlaces externos comprobados y sin promesas de integración no disponible.
- [ ] Confirmar que datos locales se pueden exportar/restaurar donde esté implementado.
- [ ] Revisar advertencias de seguridad: contenido de video/juegos solo estacionado.

## Publicación
- [ ] GitHub Pages activado y workflow verificado.
- [ ] URL pública comprobada en navegador.
- [ ] Dominio comprado por el propietario.
- [ ] DNS + certificado TLS + dominio www comprobados.
- [ ] Política de privacidad y condiciones revisadas.
- [ ] Prueba real en Tesla estacionado completada.

No anunciar «listo para producción» hasta completar los controles.
