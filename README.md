# DriverOS — Tesla Lab

Aplicación web experimental para registrar jornadas y estimar la rentabilidad de conductores de Uber y Lyft. Datos locales, sin conexión oficial con Tesla, Uber ni Lyft.

**Seguridad:** utilizar la interfaz únicamente con el vehículo estacionado.

Proyecto en desarrollo. No introducir credenciales ni datos sensibles en esta versión.
