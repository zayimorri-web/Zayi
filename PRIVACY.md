# DriverOS ONE — Información de privacidad (beta)

**Versión preliminar para revisión antes del lanzamiento.**

DriverOS ONE es una aplicación web experimental. Sus herramientas manuales pueden guardar preferencias, notas y cálculos en el almacenamiento local del navegador. Según el navegador, borrar datos del sitio puede eliminar esta información. Utilice la función de exportación cuando esté disponible.

La versión beta no solicita credenciales de Tesla, Uber, Lyft ni servicios financieros. No existe integración oficial con el vehículo, sistema de cuentas o sincronización en la nube.

Al abrir aplicaciones o mapas externos, usted abandona DriverOS ONE y se aplican las políticas de esos proveedores. No introduzca contraseñas o datos sensibles en formularios de DriverOS ONE.

Para el lanzamiento público, revisar si se añaden analíticas, formularios de contacto, cookies, servicios de terceros o backend y actualizar este documento con responsable, contacto, finalidad, conservación y derechos aplicables. No presentar este borrador como asesoría legal.
